# ADR-065: On-camera presence metrics and fairness

**Date:** 2026-10-22  
**Status:** Accepted  
**Phase:** O0 (decision only; implementation is O4)

## Decision

Framing uses relative bands. Lighting is relative (face vs background), never absolute face brightness. Reading pattern is experimental. Backgrounds are not scored. Wording is "toward camera" (ADR-029).
