# ADR-068: URL ingestion policy

**Date:** 2026-10-22  
**Status:** Accepted  
**Phase:** O0 (decision only; implementation is O6)  
**Owner decision:** OD-2 (b)

## Decision

Upload first. Link ingest is later, off by default, own content only, sandboxed, allowlisted, no cookies or DRM. YouTube Studio download is the recommended path (S73).
